Возможности

Всё управление — в одном чате

Не ещё один клиент OpenCode, а пульт к уже запущенному сервису. Никакой синхронизации баз и дублирования истории.

Сессии без границ

Создал в Telegram — появилось в TUI на ПК. Создал на ПК — видно в /sessions. Кнопка «Взять с ПК» подхватывает активную сессию.

GET /api/session

Модели и уровни мышления

Провайдер → модель → minimal / low / medium / high / max. Быстрый поиск: /model deepseek. То же для агента и плана.

POST /api/session/:id/model

Задачи с телефона

Обычный текст уходит в выбранную сессию. /task создаёт быструю сессию, если ничего не выбрано.

Git рядом

Статус, коммит, push, pull, история и ветки. Секреты и .env блокируются до коммита.

Отчёты и async

Токены, стоимость, инструменты, последний ответ и Git. Пока модель пишет, меню и кнопки продолжают отвечать.

Коннекты и MCP

Провайдеры, активные ключи CommandCode/A6API/AMD, MCP connect/disconnect. Переключил ключ — панель лимитов сразу показывает другой.

/connections

Белый список и никакого shell

Только numeric ID владельца. Бот не выполняет произвольные команды: HTTP API OpenCode и фиксированные Git-операции.

fail closed

Live-панель и уведомления

Закреплённое сообщение показывает, кто работает, какая модель и когда был апдейт. Когда сессия завершилась — приходит карточка с отчётом, даже если задача была запущена на ПК.

/live · auto

Избранное с заметками

Отметь звёздочкой нужные модели, добавь заметку и убери лишние. Файл data/favorites.json общий для всех ключей CommandCode, а переключение Command My / Comande Team — в том же меню.

/favorites · ⭐ + 📝

Файлы из модели

Модель отправляет любой файл командой tg-send.cmd, а /send путь делает это вручную. Бот также relay'ит файл, если в промте есть просьба «пришли файл» и путь.

/send · до 50 МБ

Группы и своя папка

/groups читает тот же session-folders.json, что TUI-плагин. Сессии можно переносить, переименовывать группы и удалять. Новая сессия живёт в G:\sessions\<id>.

/groups · ⚙️

Одно меню и честный /btw

Старое навигационное сообщение удаляется, поэтому панели не копятся. /btw отвечает по контексту через session.generate и не добавляет промт в историю сессии.

/btw · без мусора
Как работает

Один сервис — два экрана

Бот не хранит свою историю. Он подключается к тому же OpenCode, что и TUI, и работает через его HTTP API.

01

Telegram

Кнопки, команды и обычный текст с телефона.

02

Node-бот

Long polling, белый список, меню и промты.

03

OpenCode API

/api/session, /api/model, /api/mcp.

04

ПК

TUI, база сессий, Git и модели — всё общее.

Установка

Пять минут до первой задачи

Нужен Node.js 20+ и запущенный OpenCode. Бот ставится рядом, без облака и внешней базы.

Склонируй репозиторий

Публичный код без секретов и истории.

Создай конфиг

Скопируй config.example.json → config.json и укажи пути к service.json, папку и Git.

Добавь токен

Создай secrets/bot.env с токеном BotFather и своим username или numeric ID.

Запусти в фоне

start-silent.vbs — без окна. В Telegram отправь /start.

PowerShell / bash
# 1. Код
git clone https://github.com/Kekcek1/opencode-telegram-panel.git
cd opencode-telegram-panel/bot

# 2. Конфиг
copy config.example.json config.json

# 3. Секреты
mkdir secrets
notepad secrets\bot.env
# secrets/bot.env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_ALLOWED_USERNAME=your_username
# TELEGRAM_ALLOWED_ID=123456789
# 4. Запуск без окна
start-silent.vbs

# остановка / статус
stop.cmd
status.cmd
Если OpenCode запущен в переносимой папке, укажи путь к её state/opencode/service.json. Если сервисов несколько — переключение в боте командой /service.

Безопасность

Только ты и твой ПК

Бот не публикует сервис в интернет и не принимает команды от посторонних.

Numeric ID

Проверка по ID, а не только по username. Посторонние игнорируются, попытки попадают в access.log.

Никакого shell

Из Telegram нельзя выполнить произвольную команду. Только API OpenCode и фиксированные Git-операции.

Секреты не уедут

Токен и конфиг в .gitignore. Коммит блокирует .env, secrets, service.json и ключи.

FAQ

Коротко о главном

Почему сессии видны и на ПК, и в Telegram?

Бот не создаёт отдельную базу. Он подключается к тому же HTTP-сервису OpenCode, что и TUI, поэтому история, модели и активные сессии общие.

Нужен хостинг или облако?

Нет. Бот работает на том же ПК, где запущен OpenCode. Telegram используется только как интерфейс.

Что если запущено несколько OpenCode?

В главном меню виден URL активного сервиса. Команда /service показывает все доступные service.json и переключает бота.

Бот может выполнить любую команду на ПК?

Нет. Он умеет только вызывать API OpenCode и фиксированные Git-команды. Произвольный shell из Telegram запрещён.

Как работают уведомления о завершении?

Бот следит за активными сессиями через тот же сервис OpenCode. Когда сессия перестаёт работать, приходит карточка с моделью, временем, токенами, стоимостью и последним ответом. Это работает и для задач, запущенных на ПК.

Избранное общее для разных ключей?

Да. Избранное и скрытые модели хранятся по provider/model, поэтому не зависят от активного ключа. Переключение Command My / Comande Team меняет доступные модели, но звёздочки остаются.

Почему бот молчит?

Проверьте status.cmd и лог bot.log. Убедитесь, что OpenCode запущен и путь к service.json указан верно. Для второго сервиса используйте /service.

Можно добавить файлы и голосовые?

Это следующий слой. Сейчас панель работает с текстом; файлы, voice и permission-запросы OpenCode пока не пробрасываются.
