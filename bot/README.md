# OpenCode Panel — Telegram-пульт

Подробный отчёт по последней сессии: `SESSION-README.md`.

Бот управляет тем же OpenCode, что открыт на ПК. Сессии, модели и агенты общие:
создал в Telegram — видно в TUI; создал на ПК — видно в `/sessions`.

## Что умеет

- список сессий, выбор активной и «взять текущую с ПК»;
- новая сессия: папка → провайдер → модель → уровень мышления → агент;
- смена модели и агента/плана в активной сессии;
- обычный текст уходит в активную сессию как промт;
- `/btw вопрос` — боковой вопрос по контексту, история сессии не меняется;
- `/task текст` — быстрая задача с телефона; если сессии нет, создаст её;
- группы сессий, как в плагине TUI: `📁 Группы`, переименование, удаление, перенос;
- удаление сессии из списка с подтверждением;
- новая сессия получает свою папку `G:\sessions\<session-id>`;
- ответы и меню не блокируют друг друга: пока модель пишет, можно листать сессии,
  менять модель и отправлять `/btw`;
- красивые отчёты: токены с барами, стоимость, инструменты, Git и последний ответ;
- автоуведомление, когда сессия завершила работу;
- закреплённая live-панель с активными сессиями, обновляется каждые 20 секунд;
- избранное с заметками и скрытые модели — общее для всех ключей CommandCode;
- у каждой модели в списке есть `☆/⭐`, `🙈` и пагинация по всем моделям;
- заметки хранятся в `data/favorites.json` на диске G;
- переключение CommandCode-коннекта (`Command My`, `Comande Team`, …);
- файлы: `/send путь`, а модель может отправить файл командой `bin/tg-send.cmd`;
- одно меню вместо десятка: старое навигационное сообщение удаляется;
- подключения: провайдеры, активные ключи, MCP connect/disconnect;
- Git: статус, коммит, push, pull, история, ветки;
- `/stop` — прервать генерацию;
- `/service` — выбрать сервис, если запущено несколько OpenCode.

## Запуск

```text
G:\0_PROGRAMS\opencode-bot\start-silent.vbs
```

Запускает Node без окна. Остановить:

```text
G:\0_PROGRAMS\opencode-bot\stop.cmd
```

Проверить:

```text
G:\0_PROGRAMS\opencode-bot\status.cmd
```

Для отладки с видимым логом — `start.cmd`.

## Общий доступ с ПК

Бот читает `service.json` запущенного OpenCode и ходит в его HTTP API.
Поэтому все действия видны в TUI на ПК, а сессии с ПК видны в боте.
Если запущено несколько сервисов (portable и старый), выбери нужный через
`/service`. В главном меню показан URL активного сервиса.

## Асинхронность и меню

Промты, `/btw`, отчёты и кнопки обрабатываются независимо. Пока модель пишет,
бот продолжает принимать сообщения и нажатия. Навигационное сообщение одно:
при новом вызове меню старое удаляется, поэтому в чате не копится десяток
устаревших панелей. Закреплённая live-панель живёт отдельно.

`/btw` вызывает `session.generate`: модель отвечает по контексту, но вопрос и
ответ не добавляются в историю сессии. Поэтому в TUI на ПК не появляется
лишний промт.

## Заметки к избранному

Избранное хранится в `data/favorites.json` на диске G. Формат:

```json
{
  "favorites": {
    "commandcode/deepseek/deepseek-v4.1-flash-fast": {
      "note": "основная модель для кода",
      "added": 1795550000000
    }
  },
  "hidden": []
}
```

В `/favorites` у каждой модели есть `📝` для заметки и `🗑` для удаления.
Заметки общие для всех ключей CommandCode.

## Отправка файлов

- `/send G:\путь\файл` — отправить файл вручную.
- Модель может отправить файл командой:

```text
G:\0_PROGRAMS\opencode-bot\bin\tg-send.cmd "G:\путь\файл"
```

- Если в промте есть просьба «пришли файл» и путь, бот сам отправит найденный
  файл после ответа. Можно также указать в ответе маркер
  `[[send-file: G:\путь\файл]]`.
- Лимит Telegram Bot API — 50 МБ на файл.

## Группы и удаление сессий

`/groups` открывает те же категории, что левая панель плагина `commandcode-sessions`:
файл `state/opencode/latest/tui/plugin.commandcode.sessions.session-folders.json`.
Можно создать, переименовать и удалить группу, перенести сессию, убрать из группы.
Удаление сессии удаляет её из OpenCode и из всех групп.

В списке сессий кнопка `⚙️` открывает детали: выбрать, группа, переименовать, удалить.

## Git

Бот работает в папке активной сессии или выбранного репозитория
(кнопка `📁 Репо`). Поддерживает:

- `git status` с веткой, ahead/behind и списком изменений;
- `git add -A` + `git commit` по сообщению из Telegram;
- `git push` и `git pull --ff-only`;
- историю и список веток.

Перед коммитом бот блокирует пути, похожие на секреты: `secrets`, `.env`,
`providers.env`, `service.json`, `id_rsa`, `*.pem`, `*.key`. Push идёт без
окна входа: используется `wincred` из PortableGit.

## Безопасность

- Белый список: numeric ID и username хранятся в `secrets/bot.env`.
- Неизвестные пользователи игнорируются, попытки пишутся в `access.log`.
- Токен бота лежит в `secrets/bot.env` и не коммитится.
- Пароль сервиса читается из `service.json` и нигде не логируется.
- Бот не выполняет произвольные shell-команды из Telegram. Только API OpenCode
  и фиксированные Git-команды.

Требуется Node.js 20+ и запущенный OpenCode. Git-операции — через
`G:\0_PROGRAMS\PortableGit`.
