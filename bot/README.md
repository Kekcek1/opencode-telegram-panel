# OpenCode Panel — Telegram-пульт

Бот управляет тем же OpenCode, что открыт на ПК. Сессии, модели и агенты общие:
создал в Telegram — видно в TUI; создал на ПК — видно в `/sessions`.

## Что умеет

- список сессий, выбор активной и «взять текущую с ПК»;
- новая сессия: папка → провайдер → модель → уровень мышления → агент;
- смена модели и агента/плана в активной сессии;
- обычный текст уходит в активную сессию как промт;
- `/btw текст` — вклиниться в текущую работу (`delivery: steer`);
- `/task текст` — быстрая задача с телефона; если сессии нет, создаст её;
- красивые отчёты: токены с барами, стоимость, инструменты, Git и последний ответ;
- автоуведомление, когда сессия завершила работу;
- закреплённая live-панель с активными сессиями, обновляется каждые 20 секунд;
- избранное и скрытые модели — общее для всех ключей CommandCode;
- переключение CommandCode-коннекта (`Command My`, `Comande Team`, …);
- подключения: провайдеры, активные ключи, MCP connect/disconnect;
- Git: статус, коммит, push, pull, история, ветки;
- `/stop` — прервать генерацию;
- `/service` — выбрать сервис, если запущено несколько OpenCode.

## Запуск

```text
start-silent.vbs
```

Запускает Node без окна. Остановить:

```text
stop.cmd
```

Проверить:

```text
status.cmd
```

Для отладки с видимым логом — `start.cmd`.

| Команда | Действие |
|---|---|
| `/start` | главное меню |
| `/sessions` | сессии и выбор |
| `/new` | новая сессия |
| `/model` | модели, избранное, скрытые, коннект; `/model deepseek` — поиск |
| `/favorites` | только избранные модели |
| `/agent` или `/plan` | сменить агента |
| `/report` | красивый отчёт по сессии |
| `/live` | обновить закреплённую live-панель |
| `/git` | Git-меню; `/git push`, `/git commit текст` |
| `/connections` | провайдеры, ключи, MCP |
| `/service` | выбор сервиса OpenCode |
| `/status` | состояние |
| `/btw текст` | вклиниться в работу |
| `/stop` | остановить генерацию |
| `/task текст` | задача с телефона |

## Общий доступ с ПК

Бот читает `service.json` запущенного OpenCode и ходит в его HTTP API.
Поэтому все действия видны в TUI на ПК, а сессии с ПК видны в боте.
Если запущено несколько сервисов (portable и старый), выбери нужный через
`/service`. В главном меню показан URL активного сервиса.

## Модели и избранное

`/model` открывает домашнюю панель:

- `⭐ Избранное` — быстрый доступ к отмеченным моделям;
- `📚 Все модели` — провайдеры и полный список;
- `🙈 Скрытые` — вернуть или убрать модели из выдачи;
- `🔑 Коннект` — переключить активный ключ CommandCode.

У каждой модели в списке есть `☆/⭐`. Избранное и скрытые хранятся по
`provider/model` и общие для всех ключей. Переключение `Command My` /
`Comande Team` меняет доступные модели, но избранное остаётся.

## Live-панель и уведомления

После `/start` бот отправляет и закрепляет сообщение «Активные сессии».
Оно обновляется каждые 20 секунд: кто работает, какая модель, когда обновлён.
Если сессия завершилась, приходит карточка с отчётом и кнопками
`📊 Отчёт` / `🖥 Открыть`. Это работает и для задач, запущенных на ПК.

## Git

Бот работает в папке активной сессии или выбранного репозитория
(кнопка `📁 Репо`). Поддерживает:

- `git status` с веткой, ahead/behind и списком изменений;
- `git add -A` + `git commit` по сообщению из Telegram;
- `git push` и `git pull --ff-only`;
- историю и список веток.

Перед коммитом бот блокирует пути, похожие на секреты: `secrets`, `.env`,
`providers.env`, `service.json`, `id_rsa`, `*.pem`, `*.key`. Push идёт без
окна входа, если Git настроен на `wincred` или другой credential helper.

## Безопасность

- Белый список: numeric ID и username хранятся в `secrets/bot.env`.
- Неизвестные пользователи игнорируются, попытки пишутся в `access.log`.
- Токен бота лежит в `secrets/bot.env` и не коммитится.
- Пароль сервиса читается из `service.json` и нигде не логируется.
- Бот не выполняет произвольные shell-команды из Telegram. Только API OpenCode
  и фиксированные Git-команды.

## Файлы

```text
bot/
├── bot.mjs              polling и запуск
├── config.json          сервисы, дефолты, whitelist
├── lib/                 API, UI, Git, промты
├── secrets/bot.env      токен и username
├── state.json           активные сессии и состояние меню
├── bot.log              лог
└── start/stop/status
```

Требуется Node.js 20+ и запущенный OpenCode. Git должен быть доступен в
`PATH` или указан в `gitExe` конфига.
